BUNDLE / REALTIME

두 연결, 하나의 번들.

제목은 함께 입력하고, 저장된 변경과 비독점 작성 상태를 서로 확인하세요.

처음에는 로컬 A/B 데이터를 불러오세요. 직접 JWT를 입력해도 됩니다. 설정 변경은 연결 해제 후 적용됩니다.

TEST SEQUENCE

직접 따라 해보기

  1. A/B 연결 → 같은 snapshot과 멤버 표시 확인
  2. 제목을 함께 입력 → 1초 무입력 / blur CRDT 저장·병합 확인
  3. 서로 작성 중 표시 확인 → blur 또는 3초 무입력으로 사라짐
  4. 날짜와 본인 코멘트 REST 저장 → 상대 변경 수신
  5. 사진 대상 / 앞 / 뒤 BundlePhoto ID 선택 → 이동 저장
  6. 공개 범위 선택 → 최종 발행 → 발행자와 읽기 전용 확인

사진 이동에는 원본 Photo ID가 아닌 BundlePhoto ID를 사용합니다. 미저장 제목은 연결 중 원격 문서와 병합하며 현재 입력을 유지합니다. 연결이 끊기면 읽기 전용이고 미저장 입력은 폐기합니다. 재연결은 서버 snapshot으로 시작합니다.

개발용 테스트 도구 · 내용 저장은 REST로 직렬 전송 · durable replay 없이 REST snapshot 복구
